# MacroDesk — Courier Support Macro Console

Professional static support-agent macro tool for GitHub Pages.

Features:
- Fast macro search with Enter/Escape shortcuts
- Shows all relevant matching cases
- Category filtering and quick-search chips
- One-click copy response
- Add, update, and delete macros
- Browser Local Storage persistence
- JSON import/export
- Responsive layout
- No backend required

## GitHub Pages
Upload `index.html`, `style.css`, `script.js`, and `macros.json` to a repository.
Then go to **Settings → Pages → Deploy from a branch → main → /(root)**.

Changes made in the browser are stored locally. Export your macros for backup.
